# Security policy

## Supported versions

WavyKit is on 0.x. Security fixes are released for the latest minor version
only.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions,
or pull requests.

Report them privately through GitHub's private vulnerability reporting on the
monorepo:
[open a private security advisory](https://github.com/wavykit/wavykit/security/advisories/new).
This applies to every WavyKit repository, including read-only package
repositories such as `wavykit/core`.

Include the affected package and version, a description of the issue, and
steps to reproduce it if you can. The maintainers will acknowledge the report,
investigate, and coordinate a fix and disclosure with you through the
advisory.
