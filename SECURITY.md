# Security policy

## Supported versions

Current is on 0.x. Security fixes are released for the latest minor version
of each package only. The former `wavykit/*` packages are abandoned and get no
fixes; move to `current/current` and `current/inertia`.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions,
or pull requests.

Report them privately through GitHub's private vulnerability reporting on the
monorepo:
[open a private security advisory](https://github.com/currentphp/monorepo/security/advisories/new).
This applies to every Current repository, including read-only package
repositories such as `currentphp/current`.

Include the affected package and version, a description of the issue, and
steps to reproduce it if you can. The maintainers will acknowledge the report,
investigate, and coordinate a fix and disclosure with you through the
advisory.
